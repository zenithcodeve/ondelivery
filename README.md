# On Delivery

Aplicación PWA para pedidos y gestión de delivery.

## Preparar Supabase
1. Abre tu proyecto en Supabase.
2. Ve a SQL Editor y pega el contenido de [supabase-schema.sql](supabase-schema.sql).
3. Ejecuta el script.
4. La app ya tomará la URL y la anon key desde [supabase-config.js](supabase-config.js).

## Publicar en GitHub Pages
1. Sube estos archivos a tu repositorio.
2. Activa GitHub Pages desde la carpeta raíz o la carpeta docs.
3. Abre la URL generada.
